# Deep-Generative-AI
Deep_Gen_AI is my passion project translating theory from Bishop's Deep Learning into hands-on code. I explore energy-based models, GANs (CIFAR-10), ICA for audio, GNNs, CheXpert, and CLIP-inspired multimodal tweaks. Raw, curious, and iterative—fork it, tweak it, and explore generative AI your way!
